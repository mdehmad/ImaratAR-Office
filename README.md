# IMARAT – Sales Office AR presentation
=====================================
index.html  landing page (renders + Launch AR)
ar.html     AR viewer (Android Chrome)
model.glb   your SketchUp model, optimised for phones (16 MB, true scale)
img/        renders
logo.png    ADD THIS: Imarat logo (light/white, transparent PNG)

1. Add logo.png, then drag this whole folder onto app.netlify.com/drop
   (or Cloudflare Pages > Upload assets). You get an https link.
2. On the Android phone, open the link > Launch AR.
3. In the 3D preview, tap "Set model point A" / "B" on two columns you
   can find on site (far apart). The phone remembers them.
4. Start AR, scan the floor slab slowly, tap the same two columns.
   Leave "Fit to measured" OFF to keep true scale. Under ~2% = good.
   Use Height if the floor sits slightly high/low.
