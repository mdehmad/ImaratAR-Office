Live: https://imaratar-office.pages.dev

| File | What it is |
|---|---|
| index.html | Landing page (renders + Launch AR) |
| ar.html | 3D preview + AR viewer |
| model.glb | Optimised SketchUp model for Android/web (true scale, metres) |
| model.usdz | Same model for iPhone/iPad (Apple AR Quick Look) |
| img/ | Renders |
| logo.png | Add the Imarat logo here (light, transparent PNG) |

## Android (Chrome)
1. Launch AR, then tap **Set start point** on the 3D model (entrance, door or column corner).
2. Stand on that spot on site and tap **Start AR**.
3. Scan the floor: the office shows at full scale on the ring. Aim at the start point and tap.
4. Turn with ⟲ ⟳ / slider until the walls line up. **Move** to re-place.
Precise mode (two columns) is under "Precise mode" in the 3D view.

## iPhone / iPad
Tap **View in AR**. Apple's AR viewer opens the office at full scale (scaling locked).
Drag to move, twist with two fingers to rotate.
